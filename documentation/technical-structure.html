Core Components

Multi-Collection Architecture

Instead of a single users collection, the project uses separate collections for customers and admins. This provides better isolation and scalability as each account type grows.

Account-Type Authorization

The JWT payload includes a type field (customer/admin). The AdminGuard checks this field to grant access to administrative routes, ensuring secure separation of duties.

Base Repository Pattern

Both CustomersRepository and AdminsRepository extend the generic BaseRepository, inheriting robust CRUD functionality while maintaining type safety for their respective schemas.
