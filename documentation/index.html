Architecture Highlights

🛡️

Security First

JWT-based authentication with Passport.js and simple Admin authorization guards.

🚀

High Performance

Powered by Fastify, the fastest web framework for Node.js, and Pino logging.

📦

Modular Design

Clean Repository pattern separating database logic from business services.

Standardized Response

All API responses follow a consistent JSON envelope with metadata.

Success Envelope

{
  "success": true,
  "data": { ... },
  "meta": {
    "timestamp": "ISO-STRING"
  }
}

Error Envelope

{
  "success": false,
  "error": {
    "code": "ErrorName",
    "message": "Human readable msg",
    "statusCode": 400
  },
  "meta": {
    "timestamp": "ISO-STRING",
    "path": "/api/resource"
  }
}

Authentication Endpoints

POST /auth/customer/register

Create a new customer account.

Public
POST /auth/customer/login

Customer authentication and JWT retrieval.

Public
POST /auth/admin/register

Create a new administrative account.

Public
POST /auth/admin/login

Admin authentication and JWT retrieval.

Public

Account Endpoints

GET /customers/me

Retrieve the authenticated customer's profile.

Bearer Auth (type: customer)
GET /admins/me Admin Only

Retrieve the authenticated admin's profile.

Bearer Auth (type: admin)
